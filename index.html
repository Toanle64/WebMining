Verus Termux Miner

Script đào VRSC one-click trên Termux

Tính năng ONE-CLICK

Tự cài đặtTự tải miner & thư viện
Chọn poolLuckPool / Vipor / Verus.farm
Tùy chỉnhVí, thread, tên máy
Gọn nhẹChỉ 1 file duy nhất

Cách sử dụng

1
Cài Termux

Tải từ F-Droid (không dùng bản trên CH Play)

→ Tải Termux
2
Chạy lệnh này trong Termux
pkg install wget -y && wget -O verus.sh https://raw.githubusercontent.com/Toanle64/WebMining/main/verus.sh && chmod +x verus.sh && ./verus.sh
3
Nhập thông tin khi được hỏi

Địa chỉ ví (R...) → Tên máy → Số thread → Chọn pool

4
Bắt đầu đào

Script tự chạy. Nhấn Ctrl + C để dừng.

Tải file thủ công

Nếu không muốn dùng lệnh, tải file về rồi chạy:

bash verus.sh
Tải verus.sh

Pool hỗ trợ

Pool Phí Min Payout
LuckPool Asia Mặc định 1% 0.0001
LuckPool NA 1% 0.0001
Vipor 0.8% 0.001
Verus.farm 0.3% 0.01

Lưu ý

!

• Dùng địa chỉ ví bắt đầu bằng R (ví Verus Mobile)
• Không dùng địa chỉ sàn
• Nên để thread = số nhân CPU trừ 1 hoặc 2
• Coin tự về ví khi đạt min payout
• Máy sẽ nóng, nên cắm sạc + để mát
