🔧 Sửa lỗi thường gặp

Copy lệnh tương ứng → dán Termux → Enter. Làm theo thứ tự nếu lỗi chồng.

1. CANNOT LINK … SSL_set_quic / curl hỏng / pkg fail

Thư viện OpenSSL và libcurl lệch phiên bản. pkg dùng curl nên cũng chết.

apt update && apt full-upgrade -y
pkg reinstall -y openssl libcurl curl wget

2. No mirror / termux-change-repo

Chưa chọn kho mirror → apt/pkg không tải được.

termux-change-repo

Chọn Main → mirror Asia / Cloudflare → OK, rồi chạy lại lệnh ở mục 1.

3. pkg: command not found

Môi trường hỏng hoặc dán lệnh bị lỗi. Dùng apt:

apt update && apt full-upgrade -y && apt install -y wget curl openssl libcurl libjansson

4. Dán lệnh ra [200~ … ~

Bracketed paste. Xóa dòng lỗi, dán lại từng lệnh ngắn, hoặc:

printf '\e[?2004l'

5. CANNOT LINK ./ccminer (miner không chạy)

Binary cũ không khớp lib. Sửa lib rồi biên dịch lại trong script.

pkg reinstall -y openssl libcurl libjansson && bash $HOME/verus.sh

Trong menu NOVA bấm 4 → tự tải / biên dịch miner.

6. wget / network fail khi tải script

pkg install -y wget curl && wget -O $HOME/verus.sh https://raw.githubusercontent.com/Toanle64/WebMining/main/verus.sh && chmod +x $HOME/verus.sh && bash $HOME/verus.sh

7. Rớt pool / timeout khi đang đào

Mạng yếu hoặc pool xa. Trong menu: cấu hình lại → chọn LuckPool AP · giảm thread.

bash $HOME/verus.sh

8. Reset sạch Termux (cùng cực)

Xóa data app Termux trong Cài đặt Android → mở lại → chọn mirror → full-upgrade → chạy lệnh chính.

termux-change-repo
apt update && apt full-upgrade -y
