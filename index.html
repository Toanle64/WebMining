1 Cách sử dụng
1
Cài Termux

Tải từ F-Droid (không dùng CH Play).

→ Tải Termux
2
Cách A — Lệnh một dòng
pkg install wget -y && wget -O verus.sh https://raw.githubusercontent.com/Toanle64/WebMining/main/verus.sh && chmod +x verus.sh && ./verus.sh
3
Cách B — Tải file rồi chạy

Bấm nút bên dưới → file tải về → trong Termux:

cd /sdcard/Download && bash verus.sh
4
Nhập ví · thread · pool → đào

Giao diện màu, kiểm tra địa chỉ ví. Ctrl+C để dừng.

Coin tự về ví khi đạt min payout. Không cần đăng ký pool.
↓ Tải script

Bấm nút sẽ tải file verus.sh về máy ngay — không mở trang code GitHub.

! Lưu ý
  • Chỉ dùng địa chỉ ví bắt đầu bằng R
  • Không dùng địa chỉ sàn
  • Thread ≈ số nhân CPU trừ 1–2
  • Cắm sạc, để máy mát khi đào lâu
  • Android 64-bit (Android 7+)
