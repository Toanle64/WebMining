Script quét CPU + RAM rồi gợi ý coin phù hợp trước khi bạn chọn.
★ Gợi ý theo máy
RAM < 2.5 GB hoặc ≤ 4 core → chỉ Verus Pool, thread = max−1.
RAM ≥ 2.5 GB · 4–6 core → Verus chính; XMR/MO chỉ thử.
RAM ≥ 3.5 GB · ≥ 6 core → có thể thử MoneroOcean; VRSC vẫn dễ chạy hơn.
Cloud phone cắt core → tin số “online”, không ép thread 8 khi chỉ thấy 4.
$ Mẹo tăng thu nhập (thật tế)
1. Nhiều máy > một máy mạnh — 10 phone 1 MH/s ổn định > 1 máy hay offline.
2. Uptime — wake-lock + tắt tối ưu pin Termux + cắm sạc. Offline = mất share.
3. Pool gần — LuckPool AP (VN/SEA), EU/NA theo vùng. Script tự gợi ý theo IP.
4. Thread = max−1 — full core dễ throttle → hashrate trung bình thấp hơn.
5. Verus Pool, không Hybrid trên phone — Hybrid cắt share đều.
6. Min payout thấp — LuckPool 0.0001 VRSC; đừng để balance “nằm” quá lâu nếu cần rút.
7. Điện / cloud rẻ — phone chỉ “lời” khi chi phí biên ≈ 0.
8. Đừng kỳ vọng giàu từ 1 MH/s — vài phần nghìn VRSC/ngày; farm hoặc PC mới ra số.
Phone mining = học + thử. Muốn có số rõ: nhiều hashrate hoặc máy để bàn.
