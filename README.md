# Verus Termux Miner

Script one-click đào **Verus Coin (VRSC)** trên Termux + trang hướng dẫn đẹp.

## Cách dùng nhanh

Mở Termux và chạy:

```bash
pkg install wget -y && wget -O verus.sh https://raw.githubusercontent.com/Toanle64/WebMining/main/verus.sh && chmod +x verus.sh && ./verus.sh
```

Script sẽ hỏi:
1. Địa chỉ ví (R...)
2. Tên máy
3. Số thread
4. Chọn pool

Sau đó tự bắt đầu đào.

## Files
| File | Mô tả |
|------|--------|
| `index.html` | Trang web hướng dẫn |
| `verus.sh` | Script đào one-click |

## Pool hỗ trợ
- LuckPool Asia / NA (1%, min 0.0001)
- Vipor (0.8%)
- Verus.farm (0.3%)

## Lưu ý
- Dùng địa chỉ ví bắt đầu bằng **R** (Verus Mobile)
- Không dùng địa chỉ sàn
- Máy sẽ nóng → cắm sạc + để mát
